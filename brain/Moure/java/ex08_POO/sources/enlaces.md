Nunca copiar/pegar estos textos al estudiante como explicación cerrada — son para que YO (el coach) contraste
conceptos y ejemplos oficiales antes de explicar, y para que Nando las consulte él mismo si quiere profundizar.

no sustituto de que él lo trabaje.
