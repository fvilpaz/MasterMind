## Consejos de Supervivencia

- **Practica:** Prueba los programas de David de la Week 4 antes de empezar.
- **Compilación:** Usa `make filter` o `make recover`.
- **Errores:** Céntrate siempre en el **primer error** que aparezca — desplázate arriba si hace falta.
- **Depuración:** Si `make filter` falla, prueba:

```bash
help50 make filter
```
