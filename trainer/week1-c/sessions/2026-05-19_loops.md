```c
#include <stdio.h> // Para printf
#include <cs50.h>  // Para get_int, si lo usas para pedir 'n'

int main(void)
{
    int n;

    // 1. Pedir el tamaño del rombo al usuario
    // (Asegúrate de que n sea al menos 1 para que el rombo tenga sentido)
    do
    {
        n = get_int("Tamaño del rombo (n): ");
    }

    // --- PARTE SUPERIOR DEL ROMBO (incluyendo la fila central más ancha) ---
    // El bucle 'i' controla la fila actual, desde 0 hasta n-1
    for (int i = 0; i < n; i++)
    {
        // Bucle para los ESPACIOS a la izquierda
        // Fórmula: n - i - 1
        for (int s = 0; s < n - i - 1; s++)
        {
            printf(" "); // Imprime un espacio
        }

        // Fórmula: 2 * i + 1
        for (int h = 0; h < 2 * i + 1; h++)
        {
            printf("#"); // Imprime un hash
        }

        printf("\n"); // Al final de cada fila, un salto de línea
    }

    // --- PARTE INFERIOR DEL ROMBO (excluyendo la fila central más ancha) ---
    // El bucle 'k' controla la fila actual, desde 0 hasta n-2
    // (Recuerda que si n=1, esta parte no se ejecuta, lo cual es correcto)
    for (int k = 0; k < n - 1; k++) // Si n=1, n-1 = 0, el bucle no se ejecuta
    {
        // Bucle para los ESPACIOS a la izquierda
        // Fórmula: k + 1
        for (int s = 0; s < k + 1; s++)
        {
            printf(" "); // Imprime un espacio
        }

        // Fórmula: 2 * n - 2 * k - 3
        for (int h = 0; h < 2 * n - 2 * k - 3; h++)
        {
            printf("#"); // Imprime un hash
        }

        printf("\n"); // Al final de cada fila, un salto de línea
    }

    return 0; // Indica que el programa finalizó correctamente
}
```

**Explicación de la anidación:**

*   **`main(void)`:** Es la función principal donde empieza tu programa.
*   **`do-while`:** Pide al usuario el valor de `n` y se asegura de que sea al menos 1.
*   **Primer `for (int i = 0; i < n; i++)`:** Este bucle es el "maestro" para la parte superior. Por cada valor de `i` (que representa la fila actual, de `0` a `n-1`), se va a generar una línea completa del rombo.
    *   **Primer `for` anidado (para espacios):** Dentro del bucle de `i`, este `for` se encarga de imprimir los espacios en blanco necesarios antes de los hashes. Utiliza la fórmula `n - i - 1`.
    *   **Segundo `for` anidado (para hashes):** Inmediatamente después de los espacios, este `for` imprime los caracteres `#` para la fila actual, usando la fórmula `2 * i + 1`.
    *   **`printf("\n")`:** Una vez que se han impreso todos los espacios y hashes de una fila, este `printf` inserta un salto de línea, moviendo el cursor a la siguiente línea para que el siguiente `i` (o `k`) empiece a dibujar la fila de abajo.

*   **Segundo `for (int k = 0; k < n - 1; k++)`:** Este bucle es el "maestro" para la parte inferior. Si `n=1`, el `n-1` será `0`, el bucle no se ejecutará, lo cual es correcto (un rombo de tamaño 1 es solo un `#`, que ya fue impreso por la parte superior).
    *   Los bucles anidados para espacios y hashes siguen la misma lógica que arriba, pero aplicando las **nuevas fórmulas** que hemos derivado para la parte inferior (`k + 1` para espacios y `2 * n - 2 * k - 3` para hashes).

**Estudiante:** Aquí ahora me viene una duda recurrente jaja height < 1 || height > 8 o usamos &&?

**Trainer:** ¡Excelente pregunta, Nando! Es una duda **muy común y crucial** en lógica booleana, así que vamos a aclararla de una vez por todas.

Piensa en lo que quieres que haga el `do-while`:
Quieres que el bucle **se repita** si la altura *no es válida*.

Una altura es **válida** si está entre 1 y 8 (inclusive). Es decir:
`height >= 1 && height <= 8`

Por lo tanto, una altura es **no válida** (y queremos que el bucle se repita) si *no* cumple la condición de validez.
Esto es lo mismo que decir:
`!(height >= 1 && height <= 8)`

Aplicando las Leyes de De Morgan (`!(A && B)` es equivalente a `!A || !B`), obtenemos:
`! (height >= 1) || ! (height <= 8)`
Que se traduce a:
`height < 1 || height > 8`

¡Así que tu intuición inicial con el `||` (OR) es **correcta**!

La condición para el `while` debe ser `height < 1 || height > 8`.

*   Si el usuario ingresa `0` (inválido): `0 < 1` es `true`. `true || false` es `true`. El bucle se repite.
*   Si el usuario ingresa `5` (válido): `5 < 1` es `false`. `5 > 8` es `false`. `false || false` es `false`. El bucle **no se repite** (termina).
*   Si el usuario ingresa `9` (inválido): `9 < 1` es `false`. `9 > 8` es `true`. `false || true` es `true`. El bucle se repite.
